# Hardware Zona Oeste S.A. - Módulo de Integración PayPal
## Descripción del Proyecto
En este repositorio se alberga la documentación técnica y funcional para la integración de la API internacional de **PayPal** en la plataforma e-commerce de **Hardware Zona Oeste S.A.**, permitiendo el cobro en divisas extranjeras (USD), la conversión automática a pesos (ARS) para la facturación legal ante **ARCA**, y la gestión prioritaria de stock y despacho en el depósito.
